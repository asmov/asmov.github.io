Products

Asmov Common

Asmov Common is a modular software library and toolset that standardizes solutions for common software problems.

Bak8

Bak8 is a rotational backup system focused on providing workstation users with easily accessible daily backups of their home directories.

Backups can be configured to be archived, encrypted, and securely synchronized across multiple devices and cloud storage providers.

DirZ

DirZ is a document filing system that assists users in filing consistently, according to their own rules.

Cabinets are directories with standards that the user defines. Records are files or directories within cabinets that are named and stored according to those rules. Everything is version-controlled and synchronized across the organization.

Galacksi Orbit

Galacksi Orbit is a team-based multiplayer space-shooter set in an expanding science-fiction narrative universe.
